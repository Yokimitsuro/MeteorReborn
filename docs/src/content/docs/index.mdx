## What is Meteor Reborn?

Meteor Reborn revives [Project Meteor](https://bitbucket.org/Ioncannon/project-meteor-server),
the FFXIV 1.0 server emulator abandoned in 2019, on a modern stack. One
`docker compose up` brings up four services (login HTTP, lobby, world, map)
backed by a PostgreSQL database. A WPF launcher detects your installed FFXIV
client and patches it to 1.23b before connecting.

## Status

This is alpha software. The base flow works (login, character creation, world
connect) but zone-in is incomplete and PM's SQL dumps ship sparse content —
only 7 monster spawn locations out of the box. See the
[port notes](/MeteorReborn/architecture/port-notes/) and
[unfinished content](/MeteorReborn/project/unfinished-content/) for details.
