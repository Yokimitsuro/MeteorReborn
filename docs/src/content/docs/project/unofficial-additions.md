A scratchpad to keep track of additions made to the project which are not currently authenticated with a packet recording, or did not exist on retail. 

 

 

### Features

 

#### Gearsets

 
- The server saves the last equipped gear on a given class and will fetch what of it is in your inventory upon switching back to it
